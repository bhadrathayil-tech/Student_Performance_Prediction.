# 🎓 Student Performance Prediction using Machine Learning

A beginner-friendly machine learning project that predicts student academic performance (Pass vs. Fail) based on behavioral features such as study hours, attendance rate, and previous scores. This model helps educators identify at-risk students early and provide targeted academic interventions.

## 🚀 Project Overview
* **Objective:** Predict student success outcomes using classification algorithms.
* **Models Implemented:** 
  1. Decision Tree Classifier
  2. K-Nearest Neighbors (KNN) Classifier
* **Evaluation Metrics:** Accuracy Score and Confusion Matrix visualization.

## 📊 Dataset
* **Dataset Type:** Tabular classification dataset (generated/preprocessed for academic performance tracking).
* **Features Used:**
  * `Study_Hours`: Weekly hours dedicated to studying.
  * `Attendance`: Student attendance percentage.
  * `Previous_Score`: Past academic scores out of 100.
  * `Passed` (Target): Binary outcome (1 for Pass, 0 for Fail).

## 🛠️ Tech Stack & Requirements
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* **Environment:** Google Colab / Jupyter Notebook (`.ipynb`)
